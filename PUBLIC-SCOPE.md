# Public scope

This repository is an intentionally curated research shell.

## Included

- research theses and their limits;
- pre-registered experimental designs;
- conceptual notes about VERSO and retraversability;
- context about adjacent established ideas;
- links to other public research repositories.

## Excluded

- private sessions and raw transcripts;
- personal memory files or profile material;
- operational infrastructure, network addresses, deployment manifests, and
  local paths;
- credentials, access tokens, secrets, and private contact details;
- internal prompts, agent instructions, and tool traces;
- unreviewed code or data copied from the private working environment.

The presence of this boundary is a publication policy, not a claim that any
agentic system is secure by default. Public material remains subject to review
as it evolves.
