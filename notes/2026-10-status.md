# Status note — October 2026

**Status:** dated progress note. It contains no measurements. The
[pre-registered experiment](../experiments/2026-09-14-model-ecology-orientation/README.md)
of 2026-09-14 is unchanged and will not be rewritten; this note only records
what has happened since.

## Where the work is

The RIPLEY-LUX runtime (see [The-Ripley](https://github.com/samaeldemiurgos2-cyber/The-Ripley))
is closing the gates required before the first controlled context experiment
can run. That experiment is the first point at which any thesis in this
repository could receive evidence. Until then, every thesis keeps its current
status: hypothesis.

## How the theses are being operationalized

### "Traversal replaces compaction" now has a first test candidate

Active-context virtualization folds older parts of a conversation out of the
model's visible window and can recall them on demand, instead of summarizing
them away. That is a candidate instance of the thesis, so it will be tested
narrowly:

- **first comparison:** a baseline compressor versus fold-only virtualization;
- **one variable changed** between compared runs;
- recall, source revisits, and combinations with other systems come later and
  only if fold-only earns it.

A positive result would support the thesis for that component on that
workload. It would not prove the thesis in general, and it would not validate
VERSO.

### Orientation is identity-bearing

Context configuration is recorded before each run, including the order in
which components are composed, and order is part of the configuration's
identity. Behavior observed during a run is recorded separately and is never
allowed to stand in for what was configured. This keeps "what the model was
given" distinct from "what happened", which the orientation thesis requires.

### Relevant is not trusted

The working rules that now govern implementation:

```text
RELEVANT    != TRUSTED
RECALLED    != AUTHORITATIVE
DERIVED     != SOURCE
SUMMARIZED  != VERIFIED
PAGED-IN    != INSTRUCTION
```

A component that decides what the model sees doesn't gain authority over what
is true. This connects the context theses to the trust-boundary work in
[Agentic-Security-Research](https://github.com/samaeldemiurgos2-cyber/Agentic-Security-Research).

### Evidence must be confined to count

A comparison run is meant to count only if the worker could not reach
information outside its intended context: no host filesystem, inherited
credentials, or open network. Otherwise a context strategy could appear to
succeed because the model found the answer elsewhere. Runs without verified
confinement remain diagnostic.

## VERSO

VERSO remains a conceptual framework. No runtime implements it, and no
result from the planned experiment will be presented as proving it.
